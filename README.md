# Data Structures & Algorithms in Python

Practical implementations of core computer science data structures and recursive algorithms in Python.

## 📌 Implemented Topics & Notebooks
- **Queues:** Queue design supporting `max()` operation, reverse queue using recursion.
- **Stacks:** Stack implementations, palindrome verification using stack push/pop operations.
- **Arrays & Sorting:** Array CRUD operations, descending sort algorithms implemented without built-in functions.
- **Recursion:** Fundamental recursive algorithms and computational complexity analysis.
